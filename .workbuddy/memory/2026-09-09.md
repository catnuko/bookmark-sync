# 2026-09-09

## Vercel 部署失败修复 (bookmark-sync website)
- 现象: Vercel build 报 `ERR_PNPM_NO_LOCKFILE Cannot install with "frozen-lockfile" because pnpm-lock.yaml is absent`。
- 根因: 仓库根目录有 `pnpm-lock.yaml`（属于根项目: @supabase/supabase-js / vue / vite，服务于 extension+src），但 `website/` 是独立子项目（自带 package.json: @unhead/vue, vue-router, vue-i18n, @vitejs/plugin-vue）。`website/vercel.json` 里 `installCommand` 与 `buildCommand` 都写死 `pnpm install --frozen-lockfile`，而 website 目录缺自己的 lockfile → 失败。
- 修复: 在 `website/` 下执行 `pnpm install --lockfile-only` 生成 `website/pnpm-lock.yaml`（v9.0，pnpm 12.3.4）。注意 pnpm install 会被沙箱拦截写 store/tmp，需用 sandbox bypass。
- 待办: 该 lockfile 为未跟踪文件，需 `git add website/pnpm-lock.yaml && commit && push` 到 Vercel 部署分支后部署才会成功。用户偏好手动 git 操作，未自动 commit。
- 备注: `.gitignore` 只忽略 `website/node_modules/` 与 `website/dist/`，不忽略 lockfile，故 website/pnpm-lock.yaml 可正常提交。
