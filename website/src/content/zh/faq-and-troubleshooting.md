# 常见问题与故障排查

日常使用中最高频的疑问和故障，集中在这篇。前半是「怎么操作」，后半是「出问题了怎么办」。

## 常见问题

### 忘记同步口令怎么办？

口令是解密的唯一钥匙：口令丢失 = 云端密文无法解密，数据无法找回。请务必把口令另存到密码管理器。新版已支持盐（salt）在云端流转，跨设备只需输入同一口令，无需手动导出密钥。

### 换设备 / 重装后怎么恢复书签？

1. 在旧设备上牢记同步口令；
2. 新设备安装后登录同一账号；
3. 按引导输入同一口令；
4. 点击「立即同步」，书签自动从云端恢复，新设备会自动创建默认同步空间。

### 删除书签后还能找回吗？

不能。删除会生成「墓碑」并同步到所有设备，删除是跨设备一致的，不会被云端重新拉回。删除前请确认。

### 「同步完成」提示怎么解读？

提示按结果方向描述，不再显示推送 / 拉取条数（那是内部同步操作数，与实际书签数对不上）。首次同步完成 = 本机首次上传或云端恢复；双向同步完成 = 两端都有改动且已互相同步；已是最新 = 没有新变更。

### 可以关闭自动同步吗？

可以。选项页「高级」中可关闭自动同步开关，关闭后仅在点击「立即同步」时执行同步。

### 在 Firefox / Edge 的「其他书签」里，为什么会多出一个「账号书签栏」文件夹？

Chrome 登录了 Google 账号后，会多出来一根独立的「账号书签栏」（和本地书签栏分开）。Firefox 和 Edge 没有这根原生位置，所以扩展把这部分书签收进一个同名的「账号书签栏」文件夹，放在「其他书签」下，让你在那些浏览器里也能看到、编辑它们。这是正常设计，不是重复、也不是出错——里面的书签和你在 Chrome 里看到的完全一致，改一处、各端同步。

### 三个浏览器的书签是怎么合并的？位置会对不上吗？

三家的「书签栏 / 其他书签 / 书签菜单」位置都不一样，扩展用一套统一的标准位置把它们对齐：你在 Chrome 书签栏放的，到 Firefox 会落在工具栏、到 Edge 也一样。删除以「墓碑」同步，一端删了别端不会复活；两台设备同时改，各自的新增都保留，不会互相覆盖。唯一的小差别就是上面那条：Chrome 的「账号书签栏」在 Firefox / Edge 上没有对应根位置，会以一个文件夹的形式待在「其他书签」里。除此之外，结构和顺序各端保持一致。

## 故障排查

### 提示「N 条云端数据解密失败」？

说明同步密钥与云端数据不匹配。请检查是否输入了正确的同步口令，或是否曾更换过密钥。切勿在解密失败的状态下继续覆盖同步，以免云端数据被截断丢失。

### Chrome 里删了「书签菜单」文件夹？

只会清空菜单里的书签（会同步到所有设备），文件夹本身会自动恢复——这是设计行为，不是故障。请不要反复删除它；想清空菜单内容时，直接删除里面的书签即可。

### 开发者模式加载的扩展不更新？

通过开发者模式加载的扩展不会自动更新：改动代码后需重新构建，并在浏览器扩展管理页点击「重新加载」。

### 同步没有触发？

请检查网络与登录状态。自动同步默认开启：检测到书签变更后约 2 秒去抖推送，另每 30 分钟自动拉取一次增量。也可以在选项页手动点击「立即同步」。
